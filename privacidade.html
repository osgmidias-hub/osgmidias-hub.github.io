Política de Privacidade

Última atualização: 29 de outubro de 2026

Esta política descreve como o aplicativo OSG Midias Reports ("aplicativo"), mantido pela OSG Midias, trata os dados acessados por meio das APIs do Google.

1. Dados acessados

Com autorização expressa do usuário via Google OAuth, o aplicativo acessa:

  • Google Ads API: dados de contas, campanhas, anúncios, palavras-chave e métricas de desempenho das contas gerenciadas pela agência.
  • Google Analytics Data API (somente leitura): métricas agregadas de tráfego, sessões, conversões e receita das propriedades GA4 dos clientes.

O aplicativo não acessa e-mails, contatos, arquivos pessoais ou quaisquer outros dados da conta Google.

2. Finalidade

Os dados são usados exclusivamente para gerar relatórios de desempenho, análises e otimizações de campanhas para os próprios clientes da agência.

3. Compartilhamento

Os dados não são vendidos, alugados nem compartilhados com terceiros, exceto com o próprio cliente titular da conta, na forma de relatórios.

4. Armazenamento e segurança

As credenciais de acesso são armazenadas de forma restrita e utilizadas apenas pela equipe da agência. Os dados de desempenho são mantidos apenas enquanto necessários para a geração dos relatórios.

5. Uso de dados das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Revogação de acesso

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.
